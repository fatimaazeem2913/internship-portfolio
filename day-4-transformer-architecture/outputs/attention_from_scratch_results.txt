------------------------------------------------------------------------------------------
TEST 3: Why divide by sqrt(d_k)? (empirical demonstration)
------------------------------------------------------------------------------------------

d_k = 4:
  Raw score std dev:      1.5326
  Scaled score std dev:   0.7663
  Max weight WITHOUT scaling: 0.9048
  Max weight WITH scaling:    0.6650

d_k = 64:
  Raw score std dev:      6.6735
  Scaled score std dev:   0.8342
  Max weight WITHOUT scaling: 0.9996
  Max weight WITH scaling:    0.5321

d_k = 512:
  Raw score std dev:      24.8373
  Scaled score std dev:   1.0977
  Max weight WITHOUT scaling: 1.0000
  Max weight WITH scaling:    0.6265

Observe: as d_k grows, unscaled dot products grow in magnitude, pushing
softmax toward a one-hot distribution (max weight -> 1.0). That saturated
regime has near-zero gradient, so the model can't learn. Scaling by
sqrt(d_k) keeps the score variance ~constant regardless of d_k, holding
softmax in a healthy, trainable range. This is the entire reason the
paper's mechanism is called SCALED dot-product attention.

TEST 4: Causal (autoregressive) masking -- how GPT prevents 'cheating'
------------------------------------------------------------------------------------------

Causal mask (True = allowed to attend):
[[ True False False False]
 [ True  True False False]
 [ True  True  True False]
 [ True  True  True  True]]

Resulting attention weights:
[[1.     0.     0.     0.    ]
 [0.7471 0.2529 0.     0.    ]
 [0.3654 0.238  0.3966 0.    ]
 [0.1658 0.311  0.2297 0.2935]]

Note the strict lower-triangular structure: position 0 attends only to
itself; position 3 attends to 0,1,2,3. Every entry above the diagonal is
exactly 0.0 -- no token can see the future. This is what makes
next-token prediction a well-posed training objective.
Upper triangle all exactly zero: True

The heads produce genuinely DIFFERENT attention distributions over the

specialize in a different type of relationship, and their concatenated
outputs give the model a much richer representation than any single
attention distribution could provide.
